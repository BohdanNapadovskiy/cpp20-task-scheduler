# Task Scheduler — планувальник завдань

**Орієнтир:** 2 тижні (тижні 6–7)

## Мета
Навчитися моделювати час, керувати життєвим циклом задач і безпечно запускати процеси у Windows.

## Функціональні вимоги
- Створення, редагування, вимкнення, видалення задач: одноразовий запуск або повторення з інтервалом.
- Задача: шлях до .exe, аргументи, робочий каталог, час запуску, політика повторних спроб.
- Збереження конфігурації; журнал старту, завершення, коду виходу й помилок; ліміт паралельних запусків.
- Політика пропущених запусків: після старту виконати один раз або пропустити. Базова версія працює, доки запущений її процес.

## Технології
`std::chrono::system_clock` (календарний час), `steady_clock` (інтервали), condition_variable, JSON; WinAPI `CreateProcessW`, HANDLE у RAII-обгортці.

## План
1. Модель задачі, часові правила, стани виконання. Одноразові моменти — в UTC.
2. Сховище конфігурації та CRUD-команди з валідацією.
3. Цикл планувальника: очікує найближчий запуск і прокидається при зміні черги.
4. Запуск процесів, коректні Windows-аргументи, очікування завершення, журнал.
5. Ліміти, повторні спроби, політика пропусків. Тести через підмінюване джерело годинника.

## Критерій готовності
- [ ] Редагування задачі одразу змінює очікування
- [ ] Задача не запускається повторно всупереч політиці
- [ ] Перевірені перезапуск програми та зміна системного часу

## Розширення
Щоденні запуски з політикою часового поясу та переходів часу; Windows Service.
